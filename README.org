*Impact-hammer modal testing with NI-DAQmx* — a PySide6 desktop program for NI CompactDAQ
hardware. Version *0.1.0b1* (first beta). Licensed under the GNU GPL v3 or later.

#+begin_quote
*Disclaimer:* this program was created with the help of AI. It comes with *no guarantee of
correctness*. I have been using it quite extensively, but please check your results against a
known reference before relying on them.
#+end_quote

* What it does
- Continuous acquisition; every hit on the hammer is captured with a pre-trigger, none is missed.
- Quality checks per hit (overload, double hit, force level, decay) with a chosen action each:
  reject, ask you, accept but flag, or ignore. Automatic or manual (Accept / Reject) acceptance.
- Delete any earlier hit, or put a rejected one back, at any time; the FRF updates at once.
- Force and exponential windows (with the added damping shown); H1, H2, Hv and coherence.
- *Probe mode*: level meters with peak hold, the hammer tip's bandwidth, suggested trigger level and
  ranges — before you measure.
- Roving-hammer workflow with automatic point numbering, optionally without stopping.
- *External trigger* (e.g. high-speed camera): pulses at the start, on every hit, on every accepted
  hit, on the first hit of a point or when a point is complete, or a frame clock; every pulse logged
  with its sample index.
- Saves FRFs as UFF 58 and time data as TDMS, with hit and trigger logs.
- *Data Viewer*: FRFs, time data and spectra of saved points, re-processing, and comparison of
  several points (FRF, spectrum, time data).
- *Time data only*: with just the hammer channel (no responses) the hits are recorded and saved as
  time data, with the same trigger settings and external trigger output, and no FRFs.
- *Simulation mode*: try everything without hardware.

* Install and run
#+begin_src sh
python -m pip install .        # Python ≥ 3.9; NI-DAQmx driver from ni.com for hardware
pymodalhammer                  # or: python -m pymodalhammer
#+end_src
Without NI hardware the program starts in simulation mode.

* Documentation

* Modal analysis post-processing
The modal results saved by pymodalhammer can be used for modal analysis post-processing, including
modal fitting and SEREP, in the
[[https://github.com/Nidish96/SDynPy-WorkBench/tree/main][SDynPy WorkBench]].
